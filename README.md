# Lista de Tarefas

Aplicativo simples para organizar tarefas do dia a dia, feito com HTML, CSS e JavaScript.

Acesse: https://tatiana3016.github.io/todo-list/

## Funcionalidades

- Adicionar tarefas
- Marcar uma tarefa como feita (clique no texto)
- Excluir tarefas

## Tecnologias

- HTML
- CSS
- JavaScript
